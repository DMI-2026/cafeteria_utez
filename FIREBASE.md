# Pasos para vincular firebase con el proyecto
## Paso 1: Iniciar sesión con la cuenta del proyecto creado 
- firebase login
## Paso 2: Habilitar de forma global firebase-cli para flutter
- dart pub global activate flutterfire_cli
- En caso de pedirles que agreguen una variable de entorno, haganlo con el caso que aplique para su sistema operativo
## Paso 3: Instalar las depencias en el proyecto de flutter (apps/mobile)
- flutter pub add firebase_core firebase_auth cloud_firestore
- flutterfire configure
